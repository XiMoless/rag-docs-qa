# 指标口径对照（写简历前必读）

同一个系统在不同口径下能得出差别很大的数字，**混用就是误导**。本表把每种口径的来源、分母、适用场景钉死。

| 口径 | 值 | 分母 | 来源 | 怎么用 |
|---|---|---|---|---|
| Recall@5（v1，检索） | 0.522 | 92 可答题 | `RESULTS.md` E004 | 检索能力的标准指标，**简历主推** |
| Recall@5（全部 240，检索） | 0.586 | 220 可答题 | `RESULTS.md` E005 / `dryrun_all.jsonl` | 扩展集，样本更多但多跳题偏易，不作主口径 |
| 答案正确率（judge 三档） | 0.582（v1） | 100 题 | E004 | 端到端正确率，允许部分分 |
| 人工 OK 率 | 71% | 100 题 | `hallucination_summary.md` | 人工逐条判「断言能否被片段支持」，比 judge 严 |
| 幻觉率 strict | 2.7% | 73（排除弃答） | `hallucination_summary.md` | 最严格口径 |
| 幻觉率 guarded | 2.0% | 100（含弃答） | `hallucination_summary.md` | 常用对外口径 |
| 弃答率（关键词粗判） | 54%（v1） | 100 题 | `src/split_metrics.py` | **仅作粗估，不要引用**：回答里出现「片段里没有」就会被算成弃答，包含部分作答的情况 |
| 弃答率（人工） | 27% | 100 题 | `hallucination_summary.md` | 真实口径，引用用这个 |

## 三条铁律

1. **judge 0.582 与人工 71% 不能混用**。judge 给三档分（1 / 0.5 / 0），答对一半也算 0.5；人工审计只看「具体断言能否被 top-5 片段支持」，答一半但断言都有据算 OK，有一句编造就算 HALLUC。两个数字回答的是不同问题。
2. **幻觉率报「guarded」时必须同时说分母**。「2.0%（2/100）」比「2.0%」多一个字的信息量：它意味着分母包含弃答，如果系统更爱弃答，这个数会被压得更低。
3. **弃答率只有人工口径可信**。关键词粗判（54%）把「先拒答、然后补充有据的部分答案」也算成弃答，而人工审计把那类判 OK。看到 54% 不要慌，那是口径问题不是系统问题。
