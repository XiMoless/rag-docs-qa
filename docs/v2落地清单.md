# v2 评测集落地清单（三条命令跑完）

> 目的：v1(100 题) 只有 100 个样本，题型分布是按比例配的；v2(140 题) 加到 240 题后，
> 单跳/综合/改写/无答案四类各 60 左右，分题型结论才站得住。**v1 的结论不因 v2 作废，
> 但简历只写 v2 的数字。**

前置：五个分片齐了 —— `eval/parts/v2_partE.jsonl` … `v2_partI.jsonl`，每个 28 行。

## 1. 逐段校验（缺段会直接报错，不会静默跳过）

```powershell
Set-Location 'D:\dshwork\rag-docs-qa'; $env:PYTHONUTF8=1
foreach ($p in 'E','F','G','H','I') {
  Write-Output "=== v2_part$p ==="
  .\.venv\Scripts\python.exe -m src.validate_eval --file "eval\parts\v2_part$p.jsonl" --part $p --expect 28 2>&1 | Select-Object -Last 6
}
```

预期：每段 `errors: 0  warnings: 0`。有 warning 先看是不是「gold 术语在 source 里找不到」——那通常意味着 gold 写飞了。

## 2. 合并 + 配比检查（140 行）

```powershell
.\.venv\Scripts\python.exe -m src.build_eval_set --version v2
```

预期：`merged: 140 rows`、`duplicate questions: 0`、`duplicate gold: 0`、四个题型全 `OK`。
配比偏离 >3 会返回非 0，并列出哪一型偏了。

## 3. 检索-only 先看召回（不花钱、不占 key）

```powershell
.\.venv\Scripts\python.exe -m src.eval --set eval\eval_set_v2.jsonl --retrieval rrf --rerank --dry-run --out results\dryrun_v2.jsonl
```

判读标准：
- R@5 落在 **0.45–0.60** → 正常（v1 是 0.522），继续第 4 步
- R@5 明显低于 0.45 → 先别跑 judge，八成是新题的取材偏了（比如集中引用了同一页的深小节），查分题型召回
- R@5 超过 0.65 → 可疑，新题可能太贴近原文措辞（测不出改写能力）

## 4. 全量 judge（240 题，约 20–25 分钟，后台跑）

```powershell
.\.venv\Scripts\python.exe -m src.eval --set eval\eval_set_v2.jsonl --retrieval rrf --judge --rerank --append-results E005 --out results\eval_E005.jsonl
```

跑完自动往 `results/RESULTS.md` 追加 E005 行，「评测集」列会写成 `v2(240)`（由 `--set` 文件名推断，不是写死的）。

## 5. 幻觉审计（不能省，也不能只抽样）
